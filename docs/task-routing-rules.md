# 任务路由规则

这份文件决定“什么任务 -> 哪个状态 -> 哪个英雄”。

`route_task.py` 的匹配方式很直接：
- 先把用户任务转成小写，并把连续空白压成一个空格
- 只看 `keywords` 里哪些词完整出现在用户任务里
- 评分公式是：`命中关键词数 * 1000 + 命中关键词总长度 + priority * 10`
- 所以优先级顺序其实是：命中数 > 关键词长度 > `priority`

所以这份文件的核心目标不是“写得漂亮”，而是：
- 尽量覆盖你们日常跟龙虾对话的真实说法
- 尽量把容易混淆的任务拆开
- 让状态和英雄分配稳定，不要同一句话今天匹配吴用、明天匹配武松

### 维护规则
- 每条规则都从 `## 规则名` 开始
- 每条规则必须包含：
  - `hero`
  - `state`
  - `detail`
  - `keywords`
- `keywords` 用中文逗号或英文逗号分隔
- `state` 只能是：`idle` / `writing` / `researching` / `executing` / `syncing` / `error`
- 优先把“用户真的会说的话”写进 `keywords`
- 多写短词、口语词、技术词，不要只写正式标题
- 如果一个任务特别关键，就单开规则并给更高 `priority`，不要塞进大杂烩
