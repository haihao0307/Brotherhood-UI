# GIF Slots

Brotherhood-UI README uses these fixed GIF paths:

- `docs/media/demo-main.gif`
- `docs/media/demo-launcher.gif`
- `docs/media/demo-sync.gif`
- `docs/media/demo-routing.gif`

## How to update

1. Export your new GIF files.
2. Keep the exact filenames above.
3. Replace the existing files in this folder.
4. Commit and push.

You do not need to edit `README.md` again unless you want a different layout.
